# UHnify

UHnify is a campus community platform for UH Mānoa students. It helps students discover clubs, join organizations, manage a personal club list, and view events connected to the clubs they care about.

The app includes a modern React interface, Meteor accounts and roles, server-side methods, club/event/profile collections, and an admin dashboard for managing the system.

See `README.md` and `IMPROVEMENTS.md` for setup and handoff notes.
